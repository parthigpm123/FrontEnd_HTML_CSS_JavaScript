The ::first-line pseudo-element in CSS allows you to apply styles to the first formatted line of a block-level element. Only a specific subset of CSS properties can be used with this pseudo-element, primarily those related to fonts, backgrounds, and text appearance. W3Schools W3Schools +2 The properties that can be used with ::first-line include: All font properties: font font-family font-size font-style font-variant font-weight line-height All background properties: background background-attachment background-color background-image background-position background-repeat background-size Other text-related properties: color letter-spacing word-spacing text-decoration (and its sub-properties like text-decoration-color, text-decoration-line, text-decoration-style) text-transform text-shadow vertical-align W3Schools W3Schools +3 Properties related to the box model, such as margin, padding, and border, cannot be used with ::first-line. The length of the first line is dynamic and depends on factors like the viewport width, font size, and the element's width. Codrops Codrops +2
